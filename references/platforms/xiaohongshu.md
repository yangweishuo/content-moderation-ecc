# 小红书社区规范 - 审核要点

> 依据小红书官方社区规范、薯管家公告、治理报告整理

## 平台定位

以"标记我的生活"为核心，强调真实、有用、多元的内容分享社区。

---

## 违规处罚主要原因

根据2024年12月封号事件数据，违规原因主要有：

1. 批量发布低成本、同质化内容进行引流或牟利（薅羊毛、导流等）
2. 批量发布不符合心理预期、吸引眼球、骗取流量的内容（悬疑猎奇、互关互粉、双击有惊喜等）
3. 通过特殊身份诱导聊天或交友
4. 发布同质化交友内容，导流至其他平台
5. 其他违反平台规则的内容

- 处置账号：1,259,709个

### 重点打击方向

#### 1. 横向测评黑灰产水军
- 谎称有"内幕""黑料""避雷""信息差"
- 批量发布虚假或极低质的横向测评笔记
- 故意抹黑未与黑灰产合作的商家或机构
- **重点领域**: 医美、考研、留学、瑜伽、月子中心

#### 2. 黑灰产矩阵号
- 多账号有组织发布低质量、同质化内容
- 低成本二创内容
- 炒作性别对立博眼球
- 养号后转售，"换头"变现

## 内容审核重点

### 笔记内容
| 违规类型 | 具体表现 |
|----------|----------|
| 虚假种草 | 未实际使用即推荐，批量复制粘贴好评 |
| 虚假测评 | 夸大或捏造产品效果 |
| 导流行为 | 留微信号、引导加群、引导私信交易 |
| 炫富内容 | 过度炫耀高消费、营造虚假人设 |
| 医美违规 | 无资质宣传医美项目、夸大效果 |
| 金融违规 | 无资质推荐理财/保险产品 |
| 健康误导 | 无资质发布医疗建议、偏方 |

### 图片审核
- 不得出现过度暴露、性暗示图片
- 不得出现血腥、暴力、恐怖图片
- 不得出现违禁品图片
- 图片中嵌有二维码/联系方式视为导流

### 评论/私信
- 禁止谩骂、人身攻击
- 禁止发性骚扰内容
- 禁止广告导流

## 小红书特色规则

### "真诚分享"原则
- 笔记应基于真实体验
- 禁止付费但未标注的商业推广
- 商业内容需明确标注（品牌合作标）

### 同质化内容管控
- 禁止批量发布相似内容
- 禁止使用模板化、低质内容刷屏
- 一个账号应保持内容多样性

### 用户举报机制
- 用户可举报违规内容/账号
- 举报类型：虚假宣传、抄袭、色情、骚扰等
- 置顶/热门内容优先审核
