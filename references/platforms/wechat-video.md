# 微信视频号运营规范 - 审核要点

> 依据微信视频号官方运营规范整理

## 基本原则

1. **诚信使用**: 禁止虚假信息建立账号、误导他人、干扰真实平台数据
2. **分享优质内容**: 禁止传播有害、令人不适、不利于青少年身心健康的信息
3. **不干扰他人**: 不可对其他用户使用造成干扰

---

## 账号注册规范

### 命名规则
- 账号名应与简介内容相符
- 不得与已注册成功的账号名重复
- 不得涉及色情、暴力等违反法规内容
- 禁止使用夸大、广告性质、误导性描述
- 禁止仿冒公众人物
- 不得侵害他人姓名权、名誉权、肖像权、隐私权、知识产权

### 禁用名称
- 中国国名、国旗、国徽、军旗及中央国家机关名称
- 外国国名
- 具有民族歧视性质的名称
- 夸大宣传并存在欺骗性质的名称（如"国酒""中国第一酒"）
- 破坏社会道德风俗的名称
- 具有歧义、可能误导用户的名称
- 日常通用名词（正能量、吃货、星座、运势、爱情、健康等）
- 单独以地域名为名

### 注册限制
- 一个微信账号只能注册一个视频号
- 违规账号绑定的身份证、手机号可能被禁止再次注册
- 禁止批量注册大量相似视频号

---

## 禁止恶意使用

### 不当注册
- 恶意注册（频繁注册、批量注册、提供虚假信息）
- 买卖、出租、出借账号

### 禁止内容类型

| 类别 | 具体内容 |
|------|----------|
| 违法违规 | 危害国家安全、破坏民族团结、宣扬邪教 |
| 色情低俗 | 性行为描写、裸露、性暗示、低俗内容 |
| 暴力恐怖 | 血腥暴力、恐怖主义、极端主义 |
| 虚假信息 | 谣言、虚假新闻、伪科学 |
| 侵权内容 | 侵犯知识产权、肖像权、隐私权 |
| 赌博诈骗 | 赌博、诈骗、传销 |
| 未成年人危害 | 色情、暴力、诱导不良行为 |
| 不当营销 | 虚假广告、违规代言 |

### 诱导行为
- 诱导分享（如"转发到3个群获取"）
- 诱导关注（如"关注后回复XX获取"）
- 诱导下载
- 诱导添加个人微信

## 直播规范

### 禁止行为
- 未成年人直播
- 展示色情、低俗内容
- 饮酒、吸烟等不良行为
- 危险行为直播
- 利用直播进行诈骗
- 无资质进行医疗/金融直播

### 连麦/PK
- 不得通过PK惩罚进行低俗表演
- 不得利用连麦传播违规内容

## 内容审核要点

### 视频内容
- 标题/封面不得虚假、惊悚
- 内容不得与标题严重不符
- 不得搬运他人原创
- BGM版权需合规

### 评论区
- 不得发布违规评论
- 不得利用评论导流

### 公众号关联
- 视频号可关联公众号
- 关联后内容需保持一致调性
- 不得利用关联规避审核
