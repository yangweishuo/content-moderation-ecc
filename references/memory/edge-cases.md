# 边界案例记录

> 本文档记录审查中遇到的灰度区域案例——难以明确判定违规与否的边缘情况。
> 边界案例是系统进化的关键素材，通过积累边界案例可以：
> 1. 发现规则的模糊地带
> 2. 培养更精细的判断力
> 3. 为规则细化提供依据

---

## 边界案例分类

### 1. 广告法边界
- "极致体验"、"超凡品质"等描述词是否构成绝对化用语？
- 自媒体的产品测评（非付费）是否需按广告法审查？
- "可能是市面上最好的"——加了"可能"是否豁免？

### 2. 色情内容边界
- 健身/舞蹈视频中的紧身衣是否构成"软色情"？
- 哺乳教育视频中的裸露是否违规？
- 泳装/Bikini视频的判断标准？

### 3. 暴力内容边界
- 武术/格斗教学视频是否构成暴力展示？
- 电影解说中出现的打斗画面如何判定？
- 新闻画面中的暴力场景如何处理？

### 4. 版权边界
- 游戏实况画面是否需要游戏厂商授权？
- 多少秒的影视片段属于"合理使用"？
- AI生成的"风格模仿"作品是否侵权？

### 5. 未成年人边界
- 家长发布的孩子日常生活Vlog是否合规？
- 未成年人在监护人陪同下出镜带货是否允许？
- "萌娃"类账号的合规边界在哪里？

## 处理原则

对于边界案例，遵循以下优先级：

1. **法律优先**: 有明确法律规定的，依法律
2. **从严原则**: 涉及未成年人、国家安全，从严格
3. **平台惯例**: 参考平台的通常处理方式
4. **上下文判断**: 结合内容的整体语境，而非单一片段
5. **标记人工**: 无法判定时标记为"需人工复核"
